# Architecture Decision Records (ADRs)

## ADR-002 – Modelo de sincronização (comandos + eventos autoritativos)

**Status:** Proposed

**Decisão:** O servidor será a única fonte de verdade. Clientes enviam **comandos** (ex.: `MoveToken`). O servidor valida, persiste, gera **eventos** que são broadcast a todos os clientes da mesma sala. O protocolo inclui versão (`v1`).

**Justificativa:** Simplicidade, controle autoritativo, compatibilidade com futuros CRDTs se necessário.

**Alternativas descartadas:**
- **Estado compartilhado (CRDT)** – complexo, desnecessário para fase 0.
- **Polling** – latência maior, carga excessiva.
